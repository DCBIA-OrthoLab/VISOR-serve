# What the API PROCESS needs, and nothing else. This is the whole point of the
# migration: the server validates requests, moves files and starts processes,
# so it carries fastapi and stays on the newest Python, while every heavy
# dependency lives in a tool's own virtualenv one exec() away.
#
# Adding anything here that a TOOL needs -- numpy, pandas, torch, SimpleITK --
# undoes that: the API is pinned to whatever those packages agree on again.
# There is a test on this file (tests/test_api_requirements.py).
#
# It is also all the server image installs (docker/server.Dockerfile), and
# what docker-compose.yml re-checks at every start. requirements.txt, the whole
# tool stack the in-process image needed, is no longer installed anywhere.
fastapi
uvicorn[standard]
python-multipart
pydantic-settings
