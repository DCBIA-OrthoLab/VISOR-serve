# Heavy inference stack, kept OUT of requirements.txt on purpose.
#
# The deployment image (see docker-compose.yml) is expected to already ship
# torch built against the right CUDA version; reinstalling it on every
# container start would download gigabytes and could shadow the CUDA-enabled
# build with a CPU-only wheel. Install this file once, in the image or in the
# venv, rather than from the compose command.
#
#   ./venv/bin/pip install -r requirements-amasss.txt
#
# Until it is installed the server still starts normally and every other tool
# works: AMASSS imports torch/nnunetv2/vtk lazily and fails on its own with an
# actionable message (see tools/AMASSS/src/nnunet_runner.py).

torch
nnunetv2
# Surface (.vtk) export for AMASSS's generate_surface option.
vtk
